# Описание проекта
Проект содержит модули DAG для Airflow и скрипты к ним для построения таблиц SCD-2 типа 
с помощью PySpark 2.4.4+ и Trino.

# Инструкции по установке
Разместите модули:
- из директории dags в директорию вашего Airflow
- из директории scripts в директорию со скриптами для запуска вашего Airflow
- из директории plugins в директорию plugins вашего Airflow
